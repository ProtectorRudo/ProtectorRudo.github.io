# MICROCAOS · Quaternius Monsters · V3.9 pilot

Six distinct CC0 Quaternius monster models, stored locally to avoid CDN asset failures. Model creator: Quaternius.

Official source pack: https://quaternius.com/packs/ultimatemonsters.html (50 original creatures, CC0, commercial OK)

Companion pack: https://quaternius.itch.io/lowpoly-animated-monsters (CC0, commercial OK).

These assets were independently optimized/converted by the indicated source repositories. Each GLB SHA was verified byte-identical after transfer to this project. The models and animation sets remain the original third-party CC0 artwork. Some copies contain different animation clip names; MICROCAOS matches common idle/run/jump aliases and uses a graceful fallback when unavailable.

This pilot uses 2 monsters from Ultimate Monsters, 3 from LowPoly Animated Monsters, and 1 skeleton from the older Animated Monster Pack, all by Quaternius. Do not claim all six come from Ultimate Monsters.
